VKApp - учебное iOS-приложение (имитация) социальной сети, созданное на Swift с использованием UIKit и программной верстки.

Приложение имитирует основные возможности социальной сети: ленту публикаций, истории, друзей, фотографии, поиск, сообщения, короткие видео и создание нового контента.

1. Технологии: 
- Swift
- UIKit
- Programmatic UI
- Auto Layout
- Core Data
- AVFoundation
- AVKit
- PhotosUI
- MVVM
- Coordinator
- Repository
- Dependency Injection


2. Требования
- Xcode 26 или новее
- iOS 17.0 или новее
- iPhone или iPad (протестировано на симуляторах iPhone 17 Pro и iPad Air 13” (M4))
- Swift 6


3. Возможности приложения
3.1 Авторизация
- стартовый экран;
- вход по номеру телефона;
- сохранение пользовательской сессии;
- автоматический вход после повторного запуска;
- выход из аккаунта.

3.2 Главная лента
- список публикаций;
- изображения;
- видеопубликации;
- воспроизведение видео;
- истории;
- лайки с изменяемым количеством при действии пользователя;
- комментарии, репосты и просмотры – не активны;
- раскрытие полного текста публикации – не активно;
- переход на профиль автора.

3.3 Истории
- горизонтальный список историй;
- просмотр истории;
- создание новой истории;
- локальное хранение изображений;
- сохранение данных в Core Data.

3.4 Друзья
- список друзей;
- аватары;
- переход на профиль пользователя;

3.5 Фотографии
- сетка фотографий;
- адаптивное количество колонок;
- поддержка iPhone и iPad;
- просмотр фотографий.

3.6 Поиск
- поиск пользователей и сообществ;
- сетка рекомендованного контента;
- адаптивный layout.

3.7 Мессенджер
- список диалогов;
- экран переписки;
- отправка локальных сообщений;
- сохранение сообщений в Core Data.

3.8 Reels
- вертикальная лента видео;
- автоматическая остановка предыдущего видео;
- воспроизведение только текущего ролика;
- лайки, комментарии и просмотры;
- поддержка локальных и встроенных видео.


3.9 Создание контента
Поддерживается создание:
- истории;
- публикации;
- клипа;
- обычного видеопоста.

Изображения и видео копируются в локальное хранилище приложения. Метаданные сохраняются в Core Data.


4. Архитектура
В проекте используется сочетание нескольких подходов:

4.1 MVVM
ViewController отвечает за отображение интерфейса, а ViewModel — за подготовку данных и обработку пользовательских действий.

4.2 Repository
Работа с Core Data скрыта за протоколами репозиториев:
- FeedRepository 
- UserRepository 
- PhotoRepository 
- NotificationRepository 
- MessengerRepository 
- ReelRepository 
- AuthenticationRepository 

4.3 Coordinator
Навигацией приложения управляет AppCoordinator .

4.4 Dependency Injection
Зависимости создаются в DependencyContainer  и передаются через конструкторы.


5. Core Data
В Core Data сохраняются:
- пользователи;
- публикации;
- истории;
- фотографии;
- уведомления;
- диалоги;
- сообщения;
- Reels.

Изображения и видео не сохраняются непосредственно в Core Data. В базе хранится только имя локального файла.


6. Ограничения текущей версии
- не успел сделать профиль пользователя, локализацию, темную тему и unit-тесты
- используется только локальное хранилище;
- отсутствует серверная синхронизация;
- отсутствуют push-уведомления;
- медиаконтент хранится локально;
