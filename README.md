BestMoviesCollection 
SwiftUI-приложение для просмотра коллекции лучших фильмов с локальным
хранением данных в CoreData.
Проект разработан в рамках учебного курса по SwiftUI. Проект демонстрирует применение возможностей SwiftUI, CoreData, WebKit и анимаций в одном приложении.

Возможности
1.	просмотр списка фильмов;
2.	автоматическая сортировка фильмов по рейтингу IMDb (в случае, если рейтинг одинаковый, то сортируется по алфавиту);
3.	отображение названия, года, жанра, рейтинга и количества просмотров;
4.	экран с подробной информацией о фильме;
5.	автоматический подсчёт просмотров информации о фильме;
6.	сохранение количества просмотров в CoreData;
7.	визуализация количества просмотров с помощью анимированных полос;
8.	определение самого популярного фильма;
9.	просмотр трейлера фильма через YouTube;
10.	хранение ссылки на трейлер в CoreData;
11.	настройки отображения списка;
12.	изменение высоты строк;
13.	переключение заголовка списка;
14.	использование TabView для навигации между основными разделами.

Постеры фильмов


Главный экран
На вкладке «Фильмы» (InfoView.swift) отображается список объектов Movies, полученных из CoreData.
Для списка используется @FetchRequest, поэтому SwiftUI автоматически получает актуальные данные из локального хранилища.
Фильмы сортируются:
1.	по рейтингу IMDb --- от большего к меньшему;
2.	при одинаковом рейтинге --- по названию.
Экран информации о фильме
При выборе фильма открывается InfoDetails.
На экране отображаются:
1.	постер;
2.	название;
3.	описание;
4.	рейтинг IMDb;
5.	количество просмотров;
6.	трейлер.
Каждое открытие подробной информации увеличивает счётчик просмотров на
единицу.
Количество просмотров сохраняется в CoreData, поэтому оно не теряется
после перезапуска приложения.
Статистика
Вкладка «Статистика» (StatisticsView.swift) показывает самый популярный фильм и количество просмотров каждого фильма.
Самый популярный фильм определяется автоматически:
private var maxViews: Int64 {
    movies.map { $0.viewsCount }.max() ?? 1
}
Для каждого фильма используется визуальная шкала. При появлении экрана
ширина шкалы увеличивается с помощью SwiftUI-анимации.

Трейлеры YouTube (YoutubePlayerView.swift)
Для воспроизведения трейлеров используется WKWebView.
SwiftUI и UIKit/WebKit связываются через:
UIViewRepresentable
Ссылка на YouTube хранится непосредственно в Core Data в поле: trailerURL
Поддерживаются ссылки вида:
https://www.youtube.com/watch?v=VIDEO_ID
https://youtu.be/VIDEO_ID
https://www.youtube.com/shorts/VIDEO_ID
Для YouTube используется embedded player.
Некоторые видео могут быть недоступны для встроенного воспроизведения, если правообладатель запретил embedding. В таком случае YouTube предлагает открыть ролик непосредственно на сайте YouTube.
Анимации
В проект добавлены анимации, чтобы интерфейс был более динамичным.
Например, статистика появляется с плавным изменением ширины графиков:
.onAppear {
    isAnimated = false

    withAnimation(.easeOut(duration: 0.8)) {
        isAnimated = true
    }
}
Состояние анимации хранится в:
@State private var isAnimated = false
При необходимости аналогичный подход можно использовать для появления
карточек, изменения размеров и переходов между состояниями интерфейса.
CoreData
Сущность Movies содержит основные данные фильма:
title - String
movieDescription - String
imageName - String
rating - Double
genre - String
year - Integer 16
viewsCount - Integer 64
trailerURL - String
Начальные данные загружаются из PostData.
Перед добавлением данных выполняется проверка наличия записей в Core
Data, чтобы не создавать дубликаты при каждом запуске приложения.

Настройки
В приложении предусмотрена отдельная вкладка настроек.
Параметры сохраняются с помощью @AppStorage, поэтому выбранные
пользователем настройки сохраняются между запусками приложения.
В текущей версии доступны:
1.	включение/выключение заголовка списка;
2.	изменение высоты строк списка.
